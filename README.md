# Virtuocity

A text-focused LLM roleplaying experience. TypeScript web app, models via OpenRouter, OpenAI, Anthropic and WIRO.

```sh
npm install
npm run dev     # web app at http://localhost:5173
npm run check   # every quality gate CI runs
```
