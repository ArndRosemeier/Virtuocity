# Virtuocity

A collaboration platform where you and a cast of automated actors (language models, plain code, image models) work together in sessions. Roleplay and a book-writing room are the first session types built on it. TypeScript web app, models via OpenRouter, OpenAI and Anthropic.

```sh
npm install
npm run dev     # web app at http://localhost:5173
npm run check   # every quality gate CI runs
```
